# Политика постоянной подписи CW Trainer Pocket

**Дата ввода:** 2026-10-19. Первая совместимая сборка: `0.4.2`, `versionCode=8`.
**Имя приложения:** `com.cwtrainer.pocket`.

Публичный SHA-256 отпечаток сертификата подписи:

`FE:FA:0F:47:D6:FD:23:1C:6B:3F:9F:CD:10:6E:79:C3:06:56:97:0F:A2:8F:6B:A9:A3:46:C4:BD:59:3F:42:17`

Сертификат: CN=CW Trainer Pocket, OU=Offline Morse Trainer, O=Personal Software.

## Почему версия 0.4.1 не обновляется поверх

Предыдущие сборки подписывались случайными тестовыми ключами на разных GitHub runner. Даже если совпадают package name и версия увеличивается, Android запрещает `INSTALL_FAILED_UPDATE_INCOMPATIBLE`. Исходные закрытые ключи этих сборок недоступны. **Нельзя** обойти проверку подписи, не отключая защиту Android.

Следовательно, после 0.4.1 требуется **одна последняя переустановка** для перехода на постоянный сертификат. При удалении приложения его данные, как правило, удаляются. Начиная с 0.4.2 подписанные тем же сертификатом и с возрастающим `versionCode` APK могут обновляться обычным способом с сохранением данных.

## Где хранится закрытый ключ

Закрытый ключ хранится **только на авторизованном HOME-PC**, в пользовательской директории
`%USERPROFILE%\.cwtrainer-signing\cwtrainer-release.p12`.

Пароль к нему защищён Windows DPAPI в
`%USERPROFILE%\.cwtrainer-signing\cwtrainer-signpass.dpapi`.

Скрипт подписания:
`%USERPROFILE%\.cwtrainer-signing\Sign-CWTrainer.ps1`.

**Никогда не помещать эти три файла в GitHub**, не публиковать пароль, ключ или секреты в журнале CI. GitHub Actions только собирает и тестирует **временный debug APK**; конечный дистрибутив подписывается отдельно на HOME-PC и публикуется в `cw-trainer-android/releases/`.

## Как публиковать следующее обновление

1. Увеличить `versionCode` в `app/build.gradle.kts` (он должен строго расти).
2. Пройти `testDebugUnitTest`, `assembleDebug` и эмуляторный smoke тест.
3. Скачать test-only APK из GitHub Actions `cw-trainer-ci-temporary-debug`.
4. Выполнить локальное подписание: `powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\.cwtrainer-signing\Sign-CWTrainer.ps1" -InputApk "C:\path\ci-debug.apk" -OutputApk "C:\path\CW-Trainer-Pocket-vNEW.apk"`
5. Сверить SHA-256 сертификата с указанным выше; проверить содержимое APK, package ID, versionCode.
6. Опубликовать **только подписанную APK** в `cw-trainer-android/releases/`.
7. На Android проверить установку поверх, запуск, звук, сохранённый учебный прогресс. Не удалять старую установленную версию при нормальном обновлении.

## Резервное копирование

Файл DPAPI нельзя расшифровать после потери профиля или ключей Windows без отдельной процедуры восстановления. Для долгосрочной гарантии обновлений требуется **отдельная защищённая резервная копия** исходного `.p12` и пароля восстановления на независимом носителе. Её не следует хранить открытой в публичном GitHub. До её создания сбой HOME-PC является риском для возможности подписывать будущие обновления.

## Производственная сборка 0.4.3

Дистрибутив: `cw-trainer-android/releases/CW-Trainer-Pocket-v0.4.3.apk`.
`versionCode=9`, `versionName=0.4.3`, `applicationId=com.cwtrainer.pocket`.
SHA-256: `BAD876BDA3C9FE32914FDA1C0CD599CE1C283AC08A776820E469315E79401B96`.
Подписана **тем же постоянным сертификатом**, что 0.4.2; отладочный флаг (`debuggable`) выключен.

Для пользователей 0.4.2 установку 0.4.3 производить **поверх**, без удаления приложения. При конфликте подписи нужно остановиться и проверить, что действительно установлена версия 0.4.2 из папки `releases`, а не старая версия `*-debug.apk`.
