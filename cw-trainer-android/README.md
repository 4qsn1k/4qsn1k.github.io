# CW Trainer Pocket — Android

## v0.3: автономный учебный прототип

Техническая база: нативный Android Java, AudioTrack (650 Гц), без сети, WebView и аккаунтов.
Версия 0.3.0, Android 8.0 и выше. Учебный экран намеренно простой.

### Режимы

1. **Знакомство** — прослушать и увидеть звуковой рисунок. Первая четвёрка A/E/N/T (или А/Е/Н/Т).
2. **Тренировка** — распознать символ по звуку, выбрать одну из 4 кнопок. Правильный ответ: следующая буква через 1 секунду. При ошибке показывается правильный ответ и предлагается следующий вопрос. **Не засчитывается в освоение.**
3. **Контроль** — самостоятельно ввести услышанную букву без вариантов. После повтора записи успешный ответ помечается как «с подсказкой» и не считается независимым успешным контрольным ответом.
4. **Результат** — процент независимых ответов, текущий этап, символы с ошибками и повторения.

**Два языка**: международный и русский. Для одинакового звукового кода буквы могут отличаться; результаты хранятся раздельно. Сигналы интернациональны, отображение локализовано.

### Проверка освоения

Знакомство и тренировка не влияют на переход. Для открытия следующего символа требуется >=40 контрольных попыток, >=90% правильных ответов без повторного прослушивания, и новый символ должен быть представлен >=8 раз с >=80% точностью (в стартовом блоке проверяется каждая из четырёх букв). Эти численные критерии — **проектные**, а не доказанно оптимальные.

Автоматическое назначение повторения через 1, 3, 7 дней после успешных ответов; ошибки возвращают символ в ближайшую повторную выборку. Это начальный адаптивный механизм, не клинически или педагогически валидированная система интервального повторения.

Звуки отдельных знаков: 25 WPM внутри букв. Реальная скорость учебного потока зависит от ответа учащегося, это **не** непрерывный поток с точно рассчитанной скоростью Фарнсворта 6 WPM.

### Ограничения

- Пока нет приёма групп из 3–5 букв, слов, позывных и контроля длительной передачи.
- Нет физического телеграфного ключа и диагностики ритма.
- Нет отдельного регулируемого эффективного WPM.
- Внешнее сравнение успешности курса ещё не проводилось.
- Android CI тестирует код и имитацию Activity; проверка APK на реальном Android 16 всё ещё нужна.

### Как получить APK

[GitHub Actions](../../.github/workflows/cw-trainer-apk.yml) собирает приложение и публикует отладочный APK в папку `cw-trainer-android/dist` рабочей ветки. Для обновления используется тот же идентификатор пакета `com.cwtrainer.pocket` и увеличенная версия.

Подтверждённая методика и ссылки на литературу: [LEARNING_METHOD_EVIDENCE_RU.md](docs/LEARNING_METHOD_EVIDENCE_RU.md).

> Не обещаем, что пользователь научится Морзе за фиксированное число дней. Реальный прогресс следует оценивать по приёму ранее не предъявлявшихся последовательностей без подсказок, а не только по проценту кнопочных ответов.
