# GeoDome 2V — опытный узел с шестью гнёздами

Это отдельный **CAD-first** эксперимент. Основная страница \`geodome/index.html\` и её экспорт STL пока не меняются.

## Зачем

В предыдущем STEP цилиндрические гнёзда начинались с \`core - 5 мм\`; на пересечении со сферой получалась лишняя торцевая кромка. В эксперименте все цилиндры начинаются **внутри корпуса** и объединяются по Boolean Union в одно тело.

## Два варианта

- \`six_hub_straight.step\` — прямое объёмное соединение сферического ядра и цилиндров. Торцевого уступа нет, но математически касательное скругление отсутствует.
- \`six_hub_reinforced.step\` — тот же узел с переходными CAD loft-формами вокруг корней гнёзд. Дополнительный материал не гарантирует прочности без испытаний.

## Размеры

Гнездо Ø25,5 мм под шкант Ø25 мм, стенка 6 мм, посадка 45 мм, центр тела R30 мм, одно одностороннее отверстие Ø3,7 мм на каждом гнезде, наружная площадка Ø13 мм.

## Построение

Нужны Python, CadQuery (OpenCascade) и Trimesh.

\`\`\`bash
python build_six_hub.py
\`\`\`

Скрипт создаёт два STEP, два STL и \`settings.json\`. STEP проверяется повторным импортом как **одно корректное твердотельное тело**; STL проверяется на замкнутость. Файлы в этом каталоге генерируются локально, а не онлайн в GitHub Pages.

Следующие шаги: оценка геометрии в Fusion 360, автоматический CAD-export по JSON, испытание образцов, возможный true fillet, а затем перенос алгоритма на остальные типы узлов.

**Не рассчитано на нормативные нагрузки.** Геометрическая целостность не является доказательством эксплуатационной прочности.
