# Шаровой наконечник GeoDome — исследование рифления

Экспериментальная CAD-ветка, **не сертифицированная копия Hubs**.

В официальном Hubs Simplified.STL шар гладкий, а на фотографии литой детали видны кольцевые выступы. Геометрия рифления в официальном PDF **не определена**, поэтому приводимые здесь шаг и глубина — наши гипотезы.

Параметры по публичной спецификации: диаметр шара 16 мм, высота 30,4 мм, центр шара на высоте 25 мм от основания.

Скрипт строит три STEP и STL:

- `smooth`: без канавок;
- `grooves_0p15`: семь кольцевых канавок глубиной до 0,15 мм;
- `grooves_0p30`: семь кольцевых канавок глубиной до 0,30 мм.

Положения канавок по Z: 20,5 / 21,75 / 23 / 24,25 / 25,5 / 26,75 / 28 мм. Канавки выполняются вычитанием торов, поэтому наружная номинальная сфера остаётся Ø16 мм. Глубина, профиль и шаг **не являются обмерами оригинала**. Основание и отверстие под саморез тоже пока схематические.

## Использование

Установить Python, CadQuery и Trimesh, выполнить:

```bash
python build_ball_ribs.py
```

Скрипт экспортирует три STEP и три STL, проверит повторный импорт STEP и замкнутость STL, сформирует `qa.json`.

В Fusion 360 для сравнения использовать Inspect → Section Analysis. Это не имитация испытания механики. Отдельно нужны металлический прижим, соответствующая посадочная геометрия, испытания на выдёргивание, изгиб, усталость, УФ и ползучесть печатного материала.

Оригинальные CAD-файлы производителя намеренно не размещены в публичном репозитории.
