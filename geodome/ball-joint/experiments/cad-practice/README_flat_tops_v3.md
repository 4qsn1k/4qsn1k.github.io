# GeoDome Ball-Joint — soft-edge flat-land grooves v3

Selected base model: `ball_1_soft_015.step` from CAD Practice v1. This revision **retains the seven discrete circular bands** but rounds the groove-to-band transitions instead of using abrupt torus Boolean-cut intersections.

- Ball envelope Ø16 mm; 7 grooves, depth 0.15 mm, spacing 1.25 mm.
- Groove axial width 0.80 mm; untouched spherical land between adjacent grooves 0.45 mm.
- Groove meridian: `d(z)=0.15 × [0.5+0.5cos(π|z-c|/0.4)]³`, for `|z-c|<0.4 mm`.
- Outer land is a portion of the original sphere rather than a genuinely flat cylinder. Groove entry/exit has smoothly matched tangent and curvature.
- The main shank, mounting flange, and schematic screw hole remain as prototype geometry; these are **not exact OEM features**.
- STL and STEP generated by CadQuery; STEP reimported as one valid solid, STL checked watertight.

Run `python build_flat_tops_v3.py` with CadQuery and Trimesh. Binary STEP/STL are provided separately in the conversation archive `GeoDome_BallJoint_soft_edges_v3.zip`.

**Not structurally rated:** the actual Hubs ridges are absent from their published Simplified.STL; groove dimensions here are experimental, and print strength/fatigue/pullout are untested.
