# GeoDome: CAD-практика, шаровые наконечники и пластина

**Статус:** эксперимент. Не заменяет серийные Hubs, не подтверждает безопасную нагрузку. Исходные литые детали выполнены из УФ-стабилизированного POM, а у нас предполагается FDM-печать из PET/PETG.

Источник номинальных габаритов: предоставленный пользователем `hubs-part-specs.pdf`, страницы 4 и 5. Шар **Ø16**, центр шара **25 мм** от нижнего основания, общая длина **30,4 мм**. Металлическая фиксирующая пластина **Ø30 × 1,5 мм**, отверстие **Ø6 мм**, материал **сталь A2/304**.

Оригинальный `Ball Connector - Simplified.STL` гладкий. На фотографиях реальной литой детали заметно рифление, но точное число, радиус и глубина производителя неизвестны.

## Что строит генератор

`python build_practice.py` (потребуются CadQuery и Trimesh):

| Деталь | Контрольный параметр |
|---|---|
| `ball_0_control` | гладкий шар Ø16 |
| `ball_1_soft_015` | 7 канавок по Z, глубина 0,15 мм |
| `ball_2_middle_020` | 7 канавок, глубина 0,20 мм |
| `ball_3_deep_025` | 7 канавок, глубина 0,25 мм |
| `steel_plate_D30_t1p5_hole_6p0` | чертёжный номинал Ø6, сталь |
| `steel_plate_D30_t1p5_hole_6p4` | технологический опытный вариант Ø6,4 |
| `open_fit_bowl_R8p15/R8p3/R8p45` | открытые **не удерживающие** калибры зазора |

Центры канавок по Z = 20,5; 21,75; 23; 24,25; 25,5; 26,75; 28 мм; шаг 1,25 мм. На каждой высоте используются **разные радиусы круговых резцов**, чтобы сохранять одинаковую глубину относительно сферической оболочки. По вершинам шар остаётся Ø16.

Каждый STEP проверяется импортом и объёмом. STL проверяется на замкнутость. Для реальной металлической пластины нужно дополнительное изготовление и контроль отверстия, кромки и плоскостности.

## Практика Fusion 360

1. Импортируй `ball_0_control.step` и сохрани отдельный проект.
2. Создай эскиз на плоскости XZ с окружностью **Ø1,10 мм** и центром **X=8,35; Z=25 мм**. Выполни **Revolve → Cut → 360°** вокруг Z. Эта канавка имеет глубину ≈0,20 мм на экваторе.
3. Сделай второй эскиз: та же окружность Ø1,10 мм, но центр **X≈8,252; Z=23,75 мм**, поскольку сфера здесь имеет радиус ≈7,902 мм. Повтори Revolve Cut.
4. Добавь **Chamfer 0,3–0,4 мм** на наружную нижнюю кромку фланца, не трогай сферические поверхности.
5. Экспортируй результат в **STEP** и отправь его на проверку.

Это упражнение с двумя канавками. Не надо делать все 7 вручную. Далее проверим радиальную глубину, положение и замкнутость твердотельной модели.

**Важно:** Ø0,8-мм сопло не подходит для проверки рельефа глубиной 0,15–0,25 мм; для первого опыта предпочтительнее Ø0,4 мм с малой высотой слоя и настройкой подачи. Прочность напечатанного соединения и удержание металлическим прижимом остаются непроверенными.
