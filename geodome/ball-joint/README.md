# GeoDome — Ball-Joint (экспериментальная система узлов)

Альтернатива цельным посадочным гнёздам. Шаровые наконечники крепятся саморезами к торцам дерева и соединяются с пяти- или шестилучевыми корпусами. Исходный принцип и внешние размеры взяты из предоставленных пользователем `hubs-part-specs.pdf`, `hubs-build-instructions.pdf`, `hubs-booklet.pdf`.

**Это не оригинальные детали Hubs и не проверенная с ними совместимая замена.** Профили поднутрений, замка и зажимов в исходных чертежах заданы не полностью. Распечатанные детали могут не удерживать шар при нагрузке.

## Инструменты

- [Онлайн-генератор STL](./index.html) — настройка шара, зазора, выбор модели, STL и ZIP с ведомостью.
- [CadQuery-генератор STEP/STL](./build_ball_joint.py) — аналитические CAD-тела, точные STEP, испытанные на корректность геометрии и замкнутую STL-сетку.

## Основные размеры исходной спецификации

| Деталь | Параметр |
| --- | --- |
| 5-лучевой корпус | диаметр 52,6 мм, до центра шара 18 мм |
| 6-лучевой корпус | диаметр 54,6 мм, до центра шара 19 мм |
| Корпуса | толщина 14 мм, крепёж М6, потай Ø12,5 мм |
| Шаровой наконечник | шар Ø16 мм, от основания до центра шара 25 мм, общая высота 30,4 мм |
| Деревянный саморез | Ø4,5×65 мм |
| Прижимная пластина | Ø30×1,5 мм, металл A2/304 |
| Шаровая посадка в прототипе | радиальный зазор 0,35 мм, менять после пробной печати |

## Ведомость для полусферы 2V

6 пятилучевых + 20 шестилучевых узлов, 130 наконечников для 65 стержней, 26 стальных прижимных пластин, 26 винтов M6, 130 саморезов Ø4,5×65 мм. Для основания нужны отдельные анкеры и, возможно, дополнительные шаровые наконечники.

**Важно:** в таком шаровом соединении длина деревянного стержня меньше расстояния между геометрическими узлами примерно на 88 мм (в сумме на два конца), согласно калькулятору Hubs. Длины от нашей схемы цельных цилиндрических гнёзд использовать нельзя без пересчёта.

## CAD-экспорт локально

```bash
python -m pip install cadquery trimesh
python build_ball_joint.py --output output --ball-clearance 0.35 --neck-clearance 0.4
```

CAD-скрипт создаёт STEP и STL для двух корпусов, шарового наконечника и двух контрольных деталей, проверяет один валидный solid в STEP и watertight STL через Trimesh.

Стандартная печатная ориентация, долговечность и работа узла в готовом куполе **не проверены**. Первым делом изготовить пробную пару и провести испытание на удержание шара, вытягивание самореза, боковой изгиб, старение при УФ и температуру. В промышленном Hubs используется УФ-стабилизированный ацеталь (POM), а не бытовой PETG/бутылочный PET.

Печатная прижимная пластина — **макет**, не рабочий крепёж. Не использовать для несущего купола без механических испытаний и проектирования анкеров.
