# 4qsn1k.github.io
Интерактивные проекты, 3D-конфигураторы и калькуляторы

## Геокупол 2V — v5

**Онлайн-конструктор:** https://4qsn1k.github.io/geodome/  
**Исходник:** [geodome/index.html](geodome/index.html)  
**CAD-генератор:** [geodome/cad/build_geodome_cad_v5.py](geodome/cad/build_geodome_cad_v5.py)

### Режимы каркаса

- **Полусфера до земли:** высота = половине диаметра; 65 шкантов двух длин, 26 узлов.
- **Вытянутый до земли:** высота задаётся независимо (не ниже половины диаметра); 65 шкантов, при D=3,5 м и H=2,25 м — семь длин и шесть типов узлов. Это вертикально вытянутая геометрия 2V: углы гнёзд пересчитываются.
- **На стойках:** полусфера с нижними вертикальными стойками и обвязкой.

### Экспорт

В браузере доступны:
- **STL** — сетка для 3D-печати;
- **OBJ** — сетка для просмотра в 3D-программах;
- **3MF** — архив сетки в формате 3MF для слайсера;
- **CSV** — ведомость распила;
- **JSON** — параметры, включая режим основания и высоту.

**STEP/STP** — настоящий CAD-формат. Он создаётся отдельным генератором CadQuery/OpenCascade. Это аналитические твердотельные модели, не переименованные STL.

### Сборка STEP по JSON

1. В веб-конструкторе выбрать параметры и сохранить JSON.
2. Установить Python и CadQuery (для проверки STL также Trimesh).
3. Запустить:

```bash
python geodome/cad/build_geodome_cad_v5.py kupol_2V_nastroiki_v5.json STEP_output
```

Генератор создаёт STEP и STL для каждой разновидности узла, плюс `manifest.json`. STEP повторно импортируется и проверяется на единое корректное тело. STL проверяется на замкнутость при установленном Trimesh.

Формат `F3D` и история построения Fusion 360 в настоящее время не генерируются. Для обновления STEP через браузер потребуется CAD-сервис или браузерное CAD-ядро.

### Порядок разработки

1. Меняем `geodome/index.html` и CAD-скрипт.
2. Проверяем три режима, ведомость резки, количество узлов, STL/OBJ/3MF.
3. Проверяем STEP-экспорт по тестовому JSON.
4. Сохраняем изменения коммитами; для рискованных изменений используем ветки и pull request.
