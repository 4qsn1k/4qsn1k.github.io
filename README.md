# 4qsn1k.github.io
Интерактивные проекты, 3D-конфигураторы и калькуляторы

## Геокупол 2V

- Онлайн-конструктор (после включения GitHub Pages): https://4qsn1k.github.io/geodome/
- Исходник: [geodome/index.html](geodome/index.html)
- Возможности v4: расчёт 2V, узлы 4/5/6 направлений, настраиваемые гнёзда и крепёж, просмотр моделей, экспорт STL/ZIP/CSV/JSON.

### Как вносим изменения

1. Меняем `geodome/index.html` в GitHub.
2. Проверяем интерактивность и выгрузку STL на нескольких наборах размеров.
3. Сохраняем версию коммитом. Для крупных изменений используем отдельную ветку и pull request.
4. При ошибке откатываем изменение по истории Git.

### В разработке
- Открытые и закрытые крепления для круглых веток и прямоугольных реек.
- Калибратор деревянных концов и механическое крепление шкантов.
- Экспорт STEP с помощью CAD-ядра (пока не реализован).
- Проверка прочности на физических образцах.

**Безопасность:** этот публичный репозиторий не предназначен для токенов, паролей и других секретов. Напечатанные соединители ещё не проверены на ветровые и снеговые нагрузки.


### CAD / STEP — статус

Веб-конструктор v4 экспортирует STL (сеточная модель), CSV и JSON.
Для получения твердотельных STEP/STP подготовлен отдельный Python-генератор на CadQuery (OpenCascade). Он читает JSON, экспортированный кнопкой «Сохранить настройки JSON», и строит 4 или 5 STEP-деталей в зависимости от наличия стоек.

Пример с готовыми моделями для диаметра 3,5 м и шканта Ø25 мм передан в чате как архив `geokupol_2V_STEP_3_5m_25mm.zip`, вместе со скриптом `build_geodome_step.py`. Для своего расчёта: сохранить JSON на сайте и выполнить `python build_geodome_step.py kupol_2V_nastroiki_v4.json STEP_output` в среде с установленным CadQuery. Каждый STEP можно импортировать в Fusion 360 как твердотельную модель. Это не тождественно истории построения Fusion 360 (F3D).

Пока **прямой экспорт STEP из HTML отсутствует**; планируется объединить рабочие процессы. Геометрия STEP строится аналитически (CSG), поэтому может немного отличаться от поверхностей STL, созданных алгоритмом marching tetrahedra. Проверка CAD-модели не заменяет испытания на прочность.
