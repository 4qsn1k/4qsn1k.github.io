# SUP Маршруты

Онлайн: https://4qsn1k.github.io/sup-routes/

## Маршруты
- **Чусовая:** Коуровка — Чусовой. По GPX пользователя. Исходное значение маршрутизатора 366,9 км; сумма расстояний между географическими точками загруженного GPX около 362,3 км.
- **Воря → Угра → Ока:** Ивановское — Калуга. По GPX пользователя. Исходное значение 203 км; длина по точкам около 202,5 км. Разделение по рекам: примерно 36,4 / 155,5 / 10,6 км.

## Белая (Агидель) — маршрут в разработке
- План на май 2027: Белорецк (ориентир удобного старта у моста Р316) → Кага → Старосубхангулово → Кутаново → Юмагузинский гидроузел.
- По официальному документу гидроузел в 364 км ниже **города** Белорецка. Удобный мост Р316 расположен примерно на 12 км ниже города. Поэтому фактическая длина от выбранного стапеля меньше 364 км и **не определена точно**.
- `data/belaya-outline.geojson` содержит **9 проверяемых по источникам географических ориентиров** и **схематическую ломаную по прямым**. Ломаная **не совпадает с руслом**, не предназначена для судовождения, и её длина не является длиной реки.
- Пока пользователь не загрузит GPX по руслу, экспорт навигационного GPX этой схемы отключён, а расчёт ходовых дней является оценкой по справочной дистанции.
- Кутаново — возможный ранний финиш. Проход по Юмагузинскому водохранилищу регулируется; расположение антистапеля возле плотины НЕ подтверждено. Не приближаться к сооружениям ГЭС без разрешения.
- Ориентиры и информация: [описание сплава](https://www.ufa-prokat.ru/splav_po_beloy/), [правила Юмагузинского водохранилища](https://www.consultant.ru/document/cons_doc_LAW_203621/36faab43adc9a94dab72eb076662b978e311877e/).

## Функции
- Карта OpenFreeMap через MapLibre с переключением на спутник Esri и автономную схему GPX.
- Отображение линии GPX, границ трёх рек, расчётного километража и контрольных ориентиров.
- Каталог **154** именованных камней Чусовой. Позиции **НЕ подтверждены GPS**: километры путеводителя приблизительно спроецированы на пользовательский трек. Это визуальные подсказки, не навигационные координаты. Дополнительный список камней может быть неполным.
- Настраиваемое число ходовых дней и резерв; расчётные дневные рубежи **не являются проверенными стоянками**.
- Выбор железнодорожной стыковки из вариантов со скриншотов **октября 2026 года**. Не использовать как подтверждение движения на 2027 год.
- Добавление локальных меток по клику на карте. Данные хранятся в браузере и не отправляются на сервер.
- Экспорт GPX c метками и GeoJSON, импорт собственного GPX для временной замены маршрута.

## Ограничения
Маршруты получены из расчётных пользовательских GPX. Препятствия, завалы, опасные участки, реальные места спуска и оборудованные стоянки не проверены. Для навигации на SUP нужен актуальный трек, учёт уровня воды и правила ООПТ.

## Данные
- `data/chusovaya.geojson`: исходный GPX из Яндекс Конструктора в GeoJSON.
- `data/vorya-ugra-oka.geojson`: исходный GPX BRouter в GeoJSON, разделён по рекам.
- `data/belaya-outline.geojson`: географические опорные точки Белой; схематическая геометрия, не GPX.
- `data/stones.json`: названия и километровые отметки по [rekachusovaya.ru](https://rekachusovaya.ru/). Координаты камней здесь не содержатся.

Чужие проекты на сайте не изменены. Все файлы лежат в `/sup-routes/`.
