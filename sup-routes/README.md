# SUP Маршруты

Онлайн: https://4qsn1k.github.io/sup-routes/

## Маршруты
- **Чусовая:** Коуровка — Чусовой. По GPX пользователя. Исходное значение маршрутизатора 366,9 км; сумма расстояний между географическими точками загруженного GPX около 362,3 км.
- **Воря → Угра → Ока:** Ивановское — Калуга. По GPX пользователя. Исходное значение 203 км; длина по точкам около 202,5 км. Разделение по рекам: примерно 36,4 / 155,5 / 10,6 км.

## Белая (Агидель) — GPX добавлен
- **Старт:** Сосновка, координаты первой точки GPX: `53.870749, 58.286986`.
- **Полный финиш по файлу:** рядом с Верхнебиккузино / Юмагузинским гидроузлом: `53.005161, 56.562451`. ВАЖНО: это **не подтверждённый антистапель**, выход надо согласовать заблаговременно.
- **Маршрут:** Сосновка → Кага → Старосубхангулово → Шульган-Таш → Кутаново → Юмагузинское водохранилище → конец GPX.
- **Длина:** 347,913 км по BRouter, 347,192 км суммой расстояний между 2 024 точками.
- **Альтернатива:** сократить путь до точки русла напротив Кутаново, около **270,8 км** по GPX. Доступ с берега для транспорта не подтверждён.
- **Дневные переходы:** исходный план 7 ходовых дней и 2 резервных; примерно 49,6 км/день для полного маршрута. Дни настраиваются.
- `data/belaya.geojson` — преобразование загруженного расчётного GPX (профиль BRouter river). Присутствуют семь прямых между соседними точками длиной более 1 км, преимущественно в нижней части. Эти участки нужно сверить на спутниковой карте.
- `data/belaya-landmarks.json` — ориентиры маршрута. GPS-метки населённых пунктов **не подтверждают** возможность высадки.
- По высотной модели BRouter указан набор 1 150 м. Он **не является подъёмом на SUP**; абсолютная отметка воды уменьшается вниз по течению.
- Проход по водохранилищу, доступ к берегам, местам стоянок и гидротехническим сооружениям требует проверки текущих ограничений.
- Контекст: [описание сплава](https://www.ufa-prokat.ru/splav_po_beloy/), [правила Юмагузинского водохранилища](https://www.consultant.ru/document/cons_doc_LAW_203621/36faab43adc9a94dab72eb076662b978e311877e/).

## Функции
- Карта OpenFreeMap через MapLibre с переключением на спутник Esri и автономную схему GPX.
- Отображение линии GPX, границ трёх рек, расчётного километража и контрольных ориентиров.
- Каталог **154** именованных камней Чусовой. Позиции **НЕ подтверждены GPS**: километры путеводителя приблизительно спроецированы на пользовательский трек. Это визуальные подсказки, не навигационные координаты. Дополнительный список камней может быть неполным.
- Настраиваемое число ходовых дней и резерв; расчётные дневные рубежи **не являются проверенными стоянками**.
- Выбор железнодорожной стыковки из вариантов со скриншотов **октября 2026 года**. Не использовать как подтверждение движения на 2027 год.
- Добавление локальных меток по клику на карте. Данные хранятся в браузере и не отправляются на сервер.
- Экспорт GPX c метками и GeoJSON, импорт собственного GPX для временной замены маршрута.

## Загрузка и редактирование своих треков
- В разделе **Треки и редактирование** можно загрузить несколько файлов **GPX, KML (LineString), GeoJSON (LineString/MultiLineString)**. Файлы привязываются к активному направлению (Чусовая, Воря/Угра/Ока, Белая) и выбираются в списке.
- Если в файле несколько смежных сегментов, они объединяются в один трек. Для несвязанных линий используется самая длинная непрерывная последовательность; интерфейс сообщает о пропущенных линиях.
- **Редактировать** создаёт копию исходного трека, если личный трек ещё не выбран. Исходные GeoJSON репозитория не изменяются.
- При включённом редакторе нажмите на линию, чтобы выбрать ближайшую вершину. Перетащите подсвеченный маркер. Кнопка **+ Точка на линии** вставляет вершину рядом с выбранным участком, кнопка **− Удалить точку** удаляет выбранную вершину. Доступны **Отменить / Повторить** и клавиши Delete, Ctrl+Z, Ctrl+Y.
- Изменения **локально** сохраняются в хранилище браузера под ключом `sup-route-editor-v1`. Никакой передачи данных на GitHub или между устройствами нет. Для резервной копии экспортируйте GPX или GeoJSON.
- Импорт до 10 МБ на файл, до 100 000 координат на линию, до 15 личных треков на каждое направление. При заполнении хранилища сайт предупредит о необходимости скачать GPX.
- **Редактирование свободное**: перемещение и вставка вершин не прокладывают линию по реке автоматически. После правок нужно проверить прохождение русла на карте и спутниковых снимках.

## Ограничения
Маршруты получены из расчётных пользовательских GPX. Препятствия, завалы, опасные участки, реальные места спуска и оборудованные стоянки не проверены. Для навигации на SUP нужен актуальный трек, учёт уровня воды и правила ООПТ.

## Данные
- `data/chusovaya.geojson`: исходный GPX из Яндекс Конструктора в GeoJSON.
- `data/vorya-ugra-oka.geojson`: исходный GPX BRouter в GeoJSON, разделён по рекам.
- `data/belaya.geojson`: 2 024 точки пользовательского GPX Белой, преобразованные в GeoJSON.\n- `data/belaya-landmarks.json`: географические ориентиры Белой.
- `data/stones.json`: названия и километровые отметки по [rekachusovaya.ru](https://rekachusovaya.ru/). Координаты камней здесь не содержатся.

Чужие проекты на сайте не изменены. Все файлы лежат в `/sup-routes/`.
