# Публикация сайта через GitHub Pages

Этот репозиторий содержит публичный сайт инструментов. Исходный код серверных ботов, токены, пароли, закрытая проектная документация и базы данных здесь не размещаются.

## Включение публикации

1. Откройте **Settings → Pages** в этом репозитории.
2. Выберите **Build and deployment → Source: Deploy from a branch**.
3. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
4. Дождитесь статуса успешной публикации.
5. Откройте https://4qsn1k.github.io/ и проверьте страницу https://4qsn1k.github.io/tools/polygon/.

Сайт работает без отдельного сервера и базы данных. Telegram-боты, Node.js и Python-приложения остаются на VPS.

## Текущее состояние

- Каталог и фильтрация инструментов — работают.
- Калькулятор многоугольника, экспорт SVG/CSV — реализованы.
- Геокупол, фитосвет, водные маршруты — запланированы; их существующие приложения ещё не перенесены.
