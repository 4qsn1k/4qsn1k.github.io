# MI13 Agent для Xiaomi 13 Ultra

Версия: **0.1 (экспериментальная)**. Android 11+, HyperOS / Android 16.

## Возможности
- Управление интерфейсом Android через AccessibilityService без root.
- Чтение дерева интерфейса и получение снимков экрана через AccessibilityService.takeScreenshot.
- Анализ экрана визуальной моделью OpenAI через HTTPS API.
- Открытие приложений, нажатия, жесты, ввод текста, Назад / Домой.
- До 20 последовательных шагов на одно задание.
- Подтверждение потенциально необратимых действий в плавающем окне.
- Ручная остановка, журнал действий и диагностика без API.
- API-ключ может храниться в Android Keystore (AES-256-GCM).

## Установка
1. Установите MI13-Agent-v0.1.apk на свой телефон.
2. При необходимости откройте сведения приложения и разрешите «Ограниченные настройки».
3. Перейдите в Настройки → Специальные возможности → Загруженные приложения → MI13 Agent.
4. Включите службу MI13 Agent.
5. В настройках энергосбережения HyperOS установите «Без ограничений». При необходимости разрешите автозапуск.
6. Откройте MI13 Agent. Нажмите «Проверить доступ к экрану». Проверьте количество элементов и размер снимка.
7. Создайте отдельный OpenAI API-ключ на https://platform.openai.com/api-keys. Тариф ChatGPT не включает использование API.
8. Вставьте ключ в приложение, подтвердите передачу снимков экрана и введите задание.
9. Нажмите «ЗАПУСТИТЬ АГЕНТА». Когда потребуется разрешение, подтвердите действие в наложенном окне.
10. Для остановки откройте приложение и нажмите «СТОП». Если служба не отвечает, отключите её в настройках Специальные возможности.

## Ограничения
- Сборка и цифровая подпись проверены на HOME-PC. Реальная работа на Xiaomi 13 Ultra ещё не испытана.
- Приложение пересылает изображение экрана и доступный текст интерфейса внешнему API.
- Не используйте агент в банковских приложениях, в окнах с паролями или персональными документами.
- Взаимодействия зависят от Accessibility и настроек HyperOS. Защищённые экраны могут не передаваться.
- В версии 0.1 нет голосового интерфейса, долговременных задач или автономной работы без сети.
- Нажатия на текстовые опасные кнопки могут потребовать подтверждения. Автоматическая классификация не гарантирует обнаружение каждого рискованного действия.
- Если новая сборка подписана другим ключом, обновление поверх может не установиться.

## Сборка на Windows
Требования: Android Studio JBR/JDK и Android SDK Platform + Build Tools.
Запустите PowerShell:
  & '.\build.ps1'
Результат: MI13-Agent-v0.1.apk

Основной код находится в src/dev/mi13/agent.
Исходники доступны в отдельной ветке; основная ветка сайта не изменяется.
