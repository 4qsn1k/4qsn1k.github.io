# MI13 Agent v0.2.0 — Xiaomi 13 Ultra

## Режим «Амина» — бесплатно, без OpenAI API

Предназначен для контроля статуса официального приложения «Амина» (ru.mos.amina.app). Сервис не имитирует геопозицию, не обращается к серверам «Амины» и не подделывает подтверждения.

### Установка
1. Установите MI13-Agent-v0.2.apk. Это обновление поверх версии 0.1 при одинаковой подписи.
2. В HyperOS разрешите ограниченные настройки, если это требуется, затем включите MI13 Agent в специальных возможностях.
3. Откройте MI13 Agent → **АМИНА — ежедневная проверка бесплатно**.
4. Нажмите «Выбрать ежедневное время» и установите время. Точный сигнал требует отдельного разрешения в Android. Без него время может сместиться.
5. Разрешите уведомления. Отключите ограничения батареи для MI13 Agent и Амины.
6. При разблокированном телефоне нажмите «Проверить Амину сейчас». Проверьте журнал.
7. Если экран Амины не передаёт текст в Android Accessibility, необходима дополнительная настройка распознавания по скриншоту. Версия 0.2 такого распознавания не делает.

### Алгоритм
1. При срабатывании будильника приложение проверяет, разблокирован ли телефон.
2. При доступности службы открывает установленную «Амину».
3. Через 6,5 секунд считывает видимый текст интерфейса Амины.
4. Ищет положительный статус передачи, явные ошибки и метку времени последней передачи.
5. Если статус положительный и время последней передачи не старше 1 часа — сохраняет «подтверждено интерфейсом» и отправляет уведомление.
6. Если статус положительный, но время не распознано — сохраняет «частичная проверка», без ложного успеха.
7. Если телефон заблокирован, служба выключена или интерфейс не читается — «не проверено», уведомление.
8. Расписание восстанавливается при перезагрузке и при изменении часового пояса.

### Важно
- Это контроль **отображаемого статуса**, не серверная квитанция МВД.
- Экран Амины через этот режим не отправляется в OpenAI. Используется только локальное дерево интерфейса.
- На заблокированном устройстве нельзя автоматически обойти PIN/отпечаток. При закрытом экране проверка может не выполниться.
- Без теста на реальном телефоне нельзя подтвердить, что приложение отображает нужные поля в дереве Accessibility.
- Приложение Амина само должно передавать реальные координаты в фоновом режиме.

## Дополнительный режим ИИ
Прежний режим визуального агента сохранён и требует отдельный OpenAI API ключ. Для «Амины» не нужен.

## Сборка
На HOME-PC c Android SDK и JDK: powershell -ExecutionPolicy Bypass -File build.ps1
Результат: MI13-Agent-v0.2.apk. APK подписан тем же ключом, что v0.1.

- src/dev/mi13/agent/AminaSchedule.java — планировщик и оценка статуса
- src/dev/mi13/agent/AminaReceiver.java — будильник и рескейджулинг
- src/dev/mi13/agent/AminaMonitorActivity.java — настройки времени
- src/dev/mi13/agent/AgentService.java — служба специальных возможностей
- src/dev/mi13/agent/MainActivity.java — основное меню
