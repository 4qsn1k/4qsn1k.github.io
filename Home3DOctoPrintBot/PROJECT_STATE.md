# Состояние проекта на 2026-10-16

## Окружение

- Raspberry Pi 3B, ARMv7 (32-bit), OctoPi, OctoPrint.
- Принтер: Ender-3 S1 Pro, сопло 0,4 мм.
- Камера: Logitech C270. Снимок через `/webcam/?action=snapshot`.
- SSH-доступ и Remote Desktop Commander на Raspberry Pi.
- Бот для одного Telegram ID, доступ только в личном чате.

## Рабочая реализация

- `~/Home3DOctoPrintBot/bot_ui.py` — кнопочное меню.
- `/opt/octo-telegram/bot.py` — исходная интеграция и контроль доступа.
- `~/.config/systemd/user/home3d-octoprint-bot.service` — рабочая служба.
- `~/.config/home3d-octoprint-bot.env` — секретный конфиг, **не находится в GitHub**.
- Telegram API может быть недоступен напрямую; используется SSH-туннель через VPS и локальный loopback-only HTTPS CONNECT-прокси.
- В пользовательской systemd-сессии включены автозапуск бота, туннеля и прокси.

## Проверки

- Проверены `/start`, защита от другого ID, клавиатура 2×2, отправка /status и /photo, JPEG камеры.
- В одном из последних тестов подключение OctoPrint к принтеру было `Closed`. Статус печати, температуры и команды зависят от USB-подключения.
- Сетевая связь Telegram через VPS иногда даёт тайм-ауты. Требуется контролировать устойчивость.
