# Home3DOctoPrintBot

Приватный Telegram-бот для **OctoPrint** на Raspberry Pi. Управляет **Ender-3 S1 Pro**. Интерфейс — кнопки Telegram, без необходимости вводить команды вручную.

## Возможности

- 🖨 Состояние: подключение, G-code, прогресс, температуры.
- 📷 JPEG-снимок с Logitech C270.
- 📁 Список G-code и загрузка файла документом (до 10 МБ).
- 🎛 Пауза, продолжение и отмена печати.
- Подтверждение запуска и отмены в течение 90 секунд.
- Строгий доступ **по одному числовому Telegram ID**, только в личном чате.

**Внимание:** подтверждение в Telegram не гарантирует присутствие человека около принтера. Не запускайте нагрев или печать без местного контроля.

## Рабочая схема

`Telegram → VPS (SSH forwarding) → локальный HTTPS CONNECT-прокси → Home3D bot → OctoPrint → Ender-3 S1 Pro`.

VPS/SSH-прокси нужен только там, где недоступен `api.telegram.org:443`. Если Telegram API доступен напрямую, его можно не использовать.

## Установка и восстановление

Смотрите [docs/RECOVERY.md](docs/RECOVERY.md). Установку выполняют **на своём Raspberry Pi**.

Требуется Python 3.11+, OctoPrint, токен BotFather, отдельный ключ OctoPrint Application Keys и числовой Telegram ID владельца. Python-зависимости не требуются: используются стандартные библиотеки.

**Никогда не загружайте в GitHub** действующий `*.env`, токены, ключи OctoPrint, SSH-ключи и состояние Telegram polling.
