04 · Реальные реки и лес

Контуры из OpenStreetMap. В объёмном просмотре: синяя поверхность рек и миниатюрные деревья. Вид дерева указан только при наличии видовой информации OSM.

Ель, сосна и берёза различаются только по тегам species/genus. Без этих данных деревья условные. STL с деревьями печатается отдельно и затем приклеивается к макету.

Нажми «Загрузить OSM». Если сервер недоступен, импортируй GeoJSON.
Данные: © OpenStreetMap contributors (ODbL). Это схематический физический макет, не лесотаксационная карта.
05 · Печатные модели

3MF использует диапазоны высот и загруженные OSM-контуры лесов, рек и дорог. Это материалы поверхности, а не реальные цвета леса или воды. Для многокрасочной печати необходим совместимый слайсер и принтер.

Все расчёты выполняются прямо в браузере. Скачается ZIP: отдельные STL, схема с номерами и параметры.

Как пользоваться генератором

Редактор сетки. Перемещай всю сетку за центр или любое место внутри квадрата. Тяни белые углы для изменения охвата. Стрелки сдвигают сетку точно на 10–500 м.

Размер детали. Размер одного квадрата для принтера. Ограниченные варианты становятся неактивными. Число плиток и доступные масштабы пересчитываются.

Масштаб. 1:5000 даёт крупный рельеф, но больше плиток. Недоступные варианты отключены. Рядом написано, сколько деталей потребуется.

Высоты ×. Вертикальное преувеличение. Для горного рельефа часто подходит ×3–×8. Превышение 210 мм блокируется.

Шаг сетки STL. 0,5–1 мм — плавнее, файлы больше. Это не повышает точность исходных DEM.

3D-макет. Перетащи для вращения. Внизу горизонтальное направление инвертировано. Колесо мыши / два пальца — приближение. Shift+мышь / два пальца — сдвиг. Кнопки «Изометрия», «Сверху», «Весь макет» изменяют камеру.

PDF для типографии. A4–A0, 150–600 DPI. Установи масштаб, ориентацию и DPI. Неактивные значения превышают лимит обработки. PDF имеет реальные размеры страницы. Печатай 100%, без автоматической подгонки.

Точность. Число пикселей PDF не равно точности исходных высот. Это цветной рельеф, не кадастровая или геодезическая карта. Для типографии используется RGB, согласуй преобразование CMYK с печатником.

При экспорте загружаются настоящие высоты. Расчёт STL выполняется на устройстве; Python и внешний сервер не нужны.
