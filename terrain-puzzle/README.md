# Terrain Puzzle Generator v1.1

**Веб-приложение:** https://4qsn1k.github.io/terrain-puzzle/

Создаёт STL-макеты реального рельефа местности. Работает непосредственно в браузере. Для генерации STL не нужен сервер, Python или регистрация.

## Использование

1. Выбери два противоположных угла участка на карте или введи широту и долготу.
2. Выбери горизонтальный масштаб, размер плитки, вертикальное преувеличение и шаг сетки.
3. Программа построит квадратную область вокруг выбранных двух точек.
4. Когда большой макет превышает размер детали, программа делит его на квадраты с пазами.
5. Нажми **«Сформировать STL + схему сборки»**. Скачается ZIP.

В архиве: `STL/A01_row1_col1.stl` и следующие детали, `ASSEMBLY_PLAN.png`, `project.json`, `README_RU.txt`.

**Размер детали:** до 200×200 мм по умолчанию с учётом выступающих пазов. Шаг между соседними деталями 184 мм при глубине пазов 8 мм. Технологический зазор между соседями 0,2 мм. Основание модели 3 мм. На демонстрационных высотах проверены STL 2×2 и замкнутость сеток.

## Источники данных

- **Mapzen Terrarium**: публичные PNG-файлы числовых высот с `s3.amazonaws.com/elevation-tiles-prod/terrarium`. Исходные DEM обладают ограниченным разрешением. Это **не топографическая съёмка**.
- Карта: OpenStreetMap. При недоступности сервера приложение переключается на спутниковый слой Esri. Есть ручной переключатель на OpenTopoMap.
- В меню можно выбрать **Демо**, чтобы проверить экспорт без скачивания реального рельефа.

**Важно:** сами стили и движок карты находятся в этом репозитории: `vendor/leaflet.js`, `vendor/leaflet.css`. Внешний CDN `unpkg.com` больше не нужен. Но изображения карты и данные высот по-прежнему требуют интернет.

## Ограничения

- Нельзя получить точность отдельных деревьев, камней и берегов из высотных данных.
- Горизонтальный масштаб вычисляется по локальной равнопромежуточной аппроксимации. Для больших географических участков возможна небольшая погрешность, особенно на высоких широтах.
- Максимум 36 деталей за один расчёт. Диапазон координат не более 5° в каждой оси.
- ZIP формируется в браузере методом STORE без сжатия. Для больших проектов нужен достаточный объём памяти.
- Если суммарная высота модели превышает 210 мм, экспорт блокируется.
- Локальный Python-сервер из версии 1.0 не требуется для веб-версии. Исходный офлайн-проект хранится на HOME-PC.

## Проверки (23.10.2026)

- Сайт по GitHub Pages отдаёт HTML, карту и JavaScript: HTTP 200.
- На HOME-PC через Playwright + Microsoft Edge показаны 24 картографические плитки.
- Загрузки ZIP из браузера выполнены в режимах **Демо** и **Mapzen**.
- Реальный STL: замкнутая поверхность `is_watertight=True`; габарит 184×184×24,7 мм.
- Четыре тестовых STL 2×2: все замкнутые, объём положительный, стороны менее 200 мм.
- ZIP-архивы открыты Python zipfile без ошибок.
