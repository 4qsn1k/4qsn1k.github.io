# 🦎 ЭкзоТека — ExoTeka

Telegram-органайзер для владельцев экзотических животных. Бот: [@ExoTekaBot](https://t.me/ExoTekaBot). Python / aiogram / SQLite / Docker Compose.

## Возможности

- **Своя коллекция для каждого пользователя.** Новый пользователь открывает `/start` и выбирает «Создать свою коллекцию» или «Присоединиться по приглашению».
- **Совместный доступ для семьи.** Владелец отправляет одноразовую ссылку, действующую 48 часов. Приглашённый может изменять карточки и историю кормлений.
- **Несколько доступных коллекций.** Личная коллекция сохраняется, даже если пользователь присоединяется к семейной. Активную коллекцию можно переключить.
- **Управление доступом.** Владелец переименовывает коллекцию, просматривает участников, отменяет приглашения и отключает доступ. Участник может самостоятельно выйти.
- Карточки животных: вид, имя, даты, пол, морфа/генетика, фото, QR.
- Кормление: индивидуальный период, общий график, история, подтверждение и отмена.
- Telegram **Native Rich Messages**: Rich Tables, Buttons, Blocks, переходы внутри сообщения. Fallback на обычный Telegram.

## Запуск

Создайте `.env` по `.env.example`, задайте `BOT_TOKEN`, выполните:

```bash
docker compose up -d --build
docker compose ps
docker compose logs --tail=50
```

Откройте `/start` в личном чате с ботом. Код активации больше не нужен.

## Архитектура и документация

- `bot.py` — команды, маршрутизация, главное меню.
- `tenancy.py` — коллекции, участники, приглашения, изоляция доступа.
- `db.py`, `pet_admin_db.py` — SQLite и карточки.
- `management.py`, `settings.py` — редактирование и кормление.
- `dashboard.py`, `rich_ui.py` — таблицы и Telegram Rich UI.
- `tests/test_smoke.py` — автономная проверка.

## Приватность

Этот GitHub-репозиторий публичный. В нём **нет** реальных карточек животных, токенов, приватной базы SQLite или списка пользователей. `pets_import.json` намеренно пустой. Для восстановления реальных данных требуется отдельный закрытый backup. Лицензия пока не выбрана.
