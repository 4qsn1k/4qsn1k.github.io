# 🦎 ЭкзоТека (ExoTeka)

Telegram-органайзер для владельцев экзотических питомцев.

**Бот:** @ExoTekaBot. **Стек:** Python, aiogram, SQLite, Docker Compose.

## Возможности

- Карточки питомцев: кличка, вид, даты, пол, морфа, фотография.
- Общая коллекция с доступом нескольких разрешённых пользователей.
- Кормления: индивидуальный период, история, подтверждение и отмена.
- Сводка по всем питомцам с датой последнего и следующего кормления.
- Создание, редактирование, архивирование и восстановление карточек.
- QR-ссылка на карточку внутри Telegram.
- Telegram Native Rich Messages: Rich Tables, Rich Buttons, Rich Blocks; обычный Telegram UI как резервный вариант.

## Быстрый запуск

В каталоге `exoteka/` скопируйте `.env.example` в `.env`, настройте параметры и выполните:

```bash
docker compose up -d --build
docker compose ps
docker compose logs --tail=50
```

Для первого запуска откройте бот и отправьте `/start`. Если ID основного владельца не задан в окружении, закрепите его командой `/activate КОД`.

## Структура

`bot.py` — команды и меню; `db.py` и `pet_admin_db.py` — база; `dashboard.py` — главная таблица; `settings.py` — интервалы; `management.py` — CRUD, архив и фото; `rich_ui.py` — Rich UI и fallback; `Dockerfile` и `compose.yaml` — развёртывание.

## Защита данных

Репозиторий хранит только исходный код. Реальная база животных, приватные фото, токены и файл конфигурации сервера **не публикуются**. Здесь `pets_import.json` намеренно пустой. Восстановление реальной коллекции требует отдельной резервной копии SQLite.

Лицензия пока не выбрана.
