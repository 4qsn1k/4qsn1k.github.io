# История изменений

## 2026-10-16 — Навигация настроек

- Раздел семейного доступа перенесён с главной в «⚙️ Настройки».
- Возврат из коллекций ведёт в настройки; для гостей — на стартовый экран.
- Графики кормления остаются внутри «Мои питомцы».

## 2026-10-16 — Многопользовательская ЭкзоТека

- Отдельные коллекции для любых Telegram-пользователей.
- Ссылки-приглашения, совместное ведение, переключение между собственной и семейной базой.
- Права владельца, исключение участников, отзыв приглашений и название коллекции.
- Миграция существующей коллекции без потери карточек и истории.
- Тест на изоляцию коллекций и одноразовые приглашения.

## 2026-10-16 — Первый экспорт

- Исходники работающего MVP.
- Telegram Native Rich UI.
- Docker и документация.
- Исключены секреты и приватные данные из GitHub.
