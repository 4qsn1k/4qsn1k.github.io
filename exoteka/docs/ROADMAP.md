# План развития

## Уже работает

- Отдельные логические коллекции для любых Telegram-пользователей.
- Семейный доступ по приглашению, отзыв доступа, переключение коллекций, права владельца и редактора.
- Карточки животных, архив, фото и QR-ссылки.
- История кормлений, отдельные интервалы, подтверждение и отмена.
- Telegram Native Rich Messages с классическим fallback.

## Далее

1. Тип, количество и масса корма; отказ от еды.
2. Линьки, вес, рост и медицинские записи.
3. Уведомления о кормлении всем участникам одной коллекции.
4. Настройка уровней доступа: владелец / редактор / просмотр.
5. Журнал изменений с указанием участника.
6. Улучшенные приглашения: несколько использований, список активных приглашений.
7. Резервное копирование, пробное восстановление и мониторинг.
8. Генетика, разведение, история передачи животного.
9. Анимация успешного кормления (необязательно).
10. CI, регрессионные тесты и автоматическая синхронизация GitHub/VPS.

Правило: резервная копия → тесты на нескольких изолированных коллекциях → обновление VPS → коммит.
