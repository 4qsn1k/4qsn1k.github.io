# План развития

## Уже работает (MVP)

- Личные карточки питомцев: вид, даты, пол, морфа.
- Доступ нескольких пользователей к одной коллекции.
- Кормления: история, отмена, период, статусы на главной.
- Добавление, редактирование, архив и восстановление.
- Фото и QR-ссылка на карточку.
- Telegram Native Rich UI с fallback.

## Далее

1. Тип и количество корма, фиксация отказа от еды.
2. Линьки, вес, медицинская история, рост.
3. Напоминания о кормлении обоим пользователям.
4. Массовые отметки кормления с подтверждением.
5. Управление правами через Telegram.
6. Генетика, разведение, передача истории животного.
7. Автоматические приватные резервные копии и проверка восстановления.
8. Регрессионные тесты и GitHub Actions без секретов.
9. Необязательная анимация после подтверждения кормления.

Для каждого изменения: резервная копия → тесты → обновление VPS → коммит → актуализация документов.
