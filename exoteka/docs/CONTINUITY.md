# Контекст для продолжения проекта

**Проект:** ЭкзоТека / ExoTeka. **Бот:** @ExoTekaBot.

**Рабочий каталог VPS:** `/home/chatgpt-admin/exotic-pets-bot`. **Docker:** контейнер `exoteka-bot`.

## Принятые решения

- На главном экране сводная Rich Table со всеми питомцами и датами кормлений.
- Главное меню: «Накормил», «Обновить», «Мои питомцы», «Управление».
- Добавление — только через «Управление». Периоды — в «Мои питомцы» и персональной карточке.
- Индивидуальный период задаётся **целым числом дней**, не готовыми шаблонами.
- «Накормил» записывает результат после подтверждения, ошибочную запись можно отменить.
- Архивирование вместо безвозвратного удаления; история сохраняется.
- Rich Messages по Telegram Bot API, классический fallback.
- Два разрешённых пользователя могут редактировать одну коллекцию.

## Состояние на момент первого экспорта

На VPS есть 10 действующих карточек, для них отмечено кормление **13.10.2026**. Реальная база **не размещена** на GitHub.

## Протокол работы

1. Сначала проверьте README, архитектуру, текущий код и статус контейнера.
2. Перед исправлениями сохраните SQLite через backup API и копию исходников.
3. Тестируйте изменения на временной базе.
4. Разверните на VPS и проверьте оба аккаунта.
5. Зафиксируйте исходники отдельным коммитом GitHub. Не публикуйте .env и данные коллекции.
6. Обновите документацию, если поменялась логика.

Фраза для нового чата: «Продолжаем проект ЭкзоТека. Исходники на GitHub в каталоге exoteka/, работающий бот на VPS. Проверь README и docs/CONTINUITY.md, затем состояние контейнера. Рабочую базу и токен не трогай без необходимости».
