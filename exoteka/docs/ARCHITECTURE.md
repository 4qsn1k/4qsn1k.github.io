# Архитектура

ЭкзоТека — Telegram-бот на Python 3.12, aiogram 3.x, SQLite и Docker Compose.

## Модули

- `bot.py`: команды, маршрутизация и подтверждение кормления.
- `management.py`: создание, редактирование, фото, архив.
- `settings.py`: интервалы кормления.
- `dashboard.py`: статусы и сводная таблица.
- `rich_ui.py`: InputRichMessage, Rich Tables/Buttons/Blocks, fallback.
- `db.py`, `pet_admin_db.py`: база данных.
- `compose.yaml`: отдельный сервис с постоянным хранилищем `data/`.

## Хранимые сущности

`pets`: идентификатор, владелец, вид, пол, генотип, даты, интервал, фото, статус архива.

`feeding`: фактическая дата кормления, время фиксации, отмена ошибочной записи.

`feed_confirmations`: одноразовое подтверждение кормления.

`ui_modes`: режим оформления Telegram для каждого пользователя.

## Основные сценарии

Главная → таблица кормлений и 4 кнопки: «Накормил», «Обновить», «Мои питомцы», «Управление».

«Мои питомцы» → список → карточка → история, кормление, период; на экране списка находится общий раздел периодов.

«Управление» → добавить, изменить, архивировать, восстановить.

Кормление подтверждается перед сохранением. Новая плановая дата рассчитывается от **последнего фактического кормления** и индивидуального интервала. Если интервал отсутствует, следующую дату не рассчитывать.

Основной владелец и перечисленные в конфигурации дополнительные пользователи управляют одной коллекцией. QR-ссылка не выдаёт посторонним доступ к частным данным.
