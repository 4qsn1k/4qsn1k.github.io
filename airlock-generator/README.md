# Генератор шлюзов и межкомнатных блокировок (MVP)

Интерактивный прототип для проектирования помещений, дверей и локальных зон блокировки. Запуск: [airlock-generator](https://4qsn1k.github.io/airlock-generator/).

## Тестовая схема A–F
Помещения: A, B, C, D, E, F. Двери: AB, AE, AD, BD, CD, BC, EF, DF.

- При входе **в A**: запрещать новые проходы через AB, AE, AD.
- При переходе **F → D** через DF: запрещать новые проходы через CD, BD, AD. Двери в других помещениях не блокировать.
- Двери с одинаковым классом чистоты и перепадом давления **не исключаются автоматически**. Для них настраивается явное исключение по отдельному технологическому проекту.
- Если одновременно возникли несколько правил, запреты объединяются логическим ИЛИ.
- Открытая дверь и запрет нового доступа — разные состояния. При открытой створке команда на замок не означает физическое запирание.

## Ограничения и безопасность
Это **демонстрационный проектировщик**, не готовая система управления дверьми. Геркон показывает положение створки, но не направление прохода и не занятость помещения. Для правил вроде «человек вошёл из F в D» нужен подтверждённый источник направления (событие контроллера СКУД, проходной датчик или аналогичный источник). Одних герконов для этого недостаточно.

Пожарная эвакуация не должна зависеть от логики Owen Logic или BUSY С2000-2: независимую схему отпирания и возможность свободного выхода определяет и проверяет ответственный проектировщик.

### Резервная копия исходного Owen Logic
Файл исходного проекта хранится в `backup/Airlock_CNC_D.owle.b64` как Base64. Для восстановления под Windows:

```bat
certutil -decode Airlock_CNC_D.owle.b64 Airlock_CNC_D.owle
```

Для удобства рабочий проект на Z4559 оставлен без изменений; дополнительная резервная копия создана на рабочем столе.
