## Физический опытный стенд

**Z4559** — компьютер физического подключения. ОВЕН ПР100 (ПР100-24.1208.03.1 M02), штатное питание и DIP `Работа`. USB-RS485 CP210x `COM5`, Modbus RTU 9600/8N1, Unit ID 16. Тестовая программа/контроллер/выходы **не изменялись**.

- Подтверждён ответ FC02 для `DI1..DI8`: `0,0,1,0,0,0,0,0`.
- Подтверждён ответ FC01 для `Q1..Q8`: `0,1,1,1,0,0,0,0`.
- **Пользователь лично сверил с физическими светодиодами ПР100:** активен `DI3` и `Q2/Q3/Q4`; данные совпадают.
- Повторное открытие COM через one-shot нестабильно: **4/10 ONLINE**, часть неудач `Access denied`. Persistent агент: **11/12 ONLINE**, после одного первоначального `RTU_UNAVAILABLE` восстановился, период успешного ответа около **60–64 мс**.
- Живая SCADA ранее подтверждена на `http://127.0.0.1:8787/scada.html`, `/api/status`, `/api/project`, `/api/events`. Она показывала **демонстрационную топологию**, а не установленный шлюз. Прежний ручной экземпляр агента **штатно остановлен**, COM5 освобождён; автозапуск Windows **не установлен**.
- 19.10 при подготовке *следующего* испытания кнопок release/resume на Z4559 обнаружены два запущенных экземпляра **Owen Logic `ProgramRelayFBD.exe`**, PID **2268**, **27244**. **Аппаратное испытание не запускали, процессы не закрывали.** Не считать, что эти PID гарантированно сохранятся. После добровольного закрытия/освобождения программ оператором повторить preflight и проверить физический release/resume.
